Anyway, the fun stuff: I wanted to show you a little bit about how the Keepintouch gets made and sent!

Soooo it’s all written in HTML. These are the opening paragraphs of David’s newsletter! the <div> starts a div element, which (as Brian taught us so long ago) is like a container for other elements. I used the div here to increase the line height of the body section so it’s easier to read. The <p> and </p> enclose paragraphs, which do.. a paragraph.

Here’s the start of the question section (also from David’s newsletter). I wrapped the bright yellow <img> (image) element which contains the “Q&A” text in a <div> element that holds the cloud background gif. Since the image sits on top of the background, they look like part of the same element! You can see this if you hold and drag on the "Q&A" text of this email on a desktop. This way of stacking makes responsive sizing easier. Then we have a <p> element containing an <i> element, which just italicizes text inside of it. Then we have a <ul> (unordered list, meaning bullet points instead of numbers) containing <li> elements with the actual text in the bullet points.

And this is almost all of the code that sends the email! The kitEmails array (like a list) stores all of your emails. Within the function, I create a variable called transporter to hold the credentials of my gmail server (I have hidden the password). Then I use the info variable to call the sendMail function (which is a built in function of the platform I’m using) with the information of who it’s from, who to send it to, the subject line, and the html content (which I linked to above this code). Then I just have the function tell me if any emails rejected.

…I think. I followed a youtube tutorial for the part that actually sends the email, so I may be a little off! But that’s the gist.

Finally, I call the function in my terminal by navigating to the folder and telling node (the platform I’m using) to run app.js, which holds the sending code we just looked at. Every Friday I open this up and hit enter!
